# Open-license evaluation media

`open_media_manifest.json` records four independent Wikimedia Commons sources,
their creators, dates as described by the sources, licenses and attribution.
The files are not included in this repository and have not been uploaded to
Cloudinary by this manifest. Source dates and locations are not a substitute
for verified cleanup visit records.

These items can test media ingestion, retrieval, visual descriptions and video
timestamps. They **must not** be paired as before/after evidence or used to
claim an intervention, reduction in litter, collected weight or ecological
impact. Preserve attribution and CC BY-SA requirements if publishing adapted
media or reports containing it.
