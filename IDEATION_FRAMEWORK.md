# 💡 Problem Statement Deconstruction & Ideation Framework

> **Use this document the moment HackCulture releases the Problem Statement (PS).**  
> Fill this out collaboratively with the team during the first 2–4 hours to select the winning idea.

---

## 🔍 Step 1: Problem Statement Deconstruction (30 Mins)

Copy the exact Problem Statement below and break it down:

```markdown
### Official Problem Statement Title:
[Paste PS title here]

### Problem Summary:
[In 2-3 sentences, what is the core issue that needs solving?]

### Target Users:
[Who actually faces this problem? e.g., Students, Doctors, Developers, SMBs]

### Stated Constraints / Requirements:
- Requirement 1: ...
- Requirement 2: ...
- Tech requirements (if specified): ...
```

---

## 🧠 Step 2: 3-Idea Brainstorming & Scoring Matrix

Generate **three distinctly different approaches** to solving the problem:

| Evaluation Criteria (Score 1–10) | Idea 1: [Idea Name] | Idea 2: [Idea Name] | Idea 3: [Idea Name] |
| :--- | :---: | :---: | :---: |
| **1. Direct PS Alignment:** Does it solve the exact problem? | /10 | /10 | /10 |
| **2. Visual "Wow" Factor:** Can a judge get excited in 20 secs? | /10 | /10 | /10 |
| **3. Technical Depth:** Good mix of AI/logic/architecture? | /10 | /10 | /10 |
| **4. Hackathon Feasibility:** Can 3 devs finish it 24h early? | /10 | /10 | /10 |
| **5. Market Viability:** Is there a clear real-world use case? | /10 | /10 | /10 |
| **TOTAL SCORE (Out of 50)** | **/50** | **/50** | **/50** |

---

## 🏆 Step 3: Selected Winning Solution Details

Once an idea is selected based on highest score and team consensus, fill this section:

### 1. The One-Liner Pitch
> *"Project LEX is a [category] that helps [target audience] to [solve core pain point] by [secret sauce / AI innovation]."*

### 2. The "Unfair Advantage" (Why will judges remember us?)
- What is the ONE feature or angle no other team will think of?
- Examples: Real-time interactive simulation, hyper-personalized AI agent, offline-first sync, accessible speech/voice UI, instant verifiable audit log.

### 3. Core User Journey (The 3-Step Demo Story)
1. **Step 1 (Input/Trigger):** User opens app, provides input / uploads data / connects account.
2. **Step 2 (The Magic):** LEX engine / AI analyzes, transforms, processes in real time with visual feedback.
3. **Step 3 (The Payoff):** User gets an actionable result, interactive visualization, or automated execution.
