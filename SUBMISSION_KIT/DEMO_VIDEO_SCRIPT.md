## 🎥 Recording & Screen Capture Best Practices

1. **Clean Screen Hygiene:**
   - Hide browser bookmarks bar (`Ctrl + Shift + B`).
   - Close all unnecessary browser tabs.
   - Use browser zoom at 110% or 125% so text and buttons are crisp and easily legible on mobile viewers.
   - Turn off all desktop notifications, Discord popups, and Slack alerts.
2. **Speed Run Pre-fills:**
   - Never record yourself slowly typing long inputs or struggling with passwords.
   - Pre-fill inputs or copy-paste them instantly using keyboard shortcuts so the video remains fast-paced and punchy.
3. **Audio Quality:**
   - Do a 10-second test recording first to verify audio levels.
   - Keep your voice confident, energetic, and articulate.
4. **Export Settings:**
   - Format: `.mp4` (H.264 codec).
   - Upload to YouTube: set to **Unlisted** (or **Public**). Test link in incognito mode!
